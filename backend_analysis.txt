# DRONE PATH API - АКТУАЛЬНЫЙ BACKEND ANALYSIS

Документ обновлен по фактическому состоянию кода в репозитории (папка `src/`, `docker-compose.yml`, `package.json`, `feature_*.txt`).

## 1. Executive Summary

Проект представляет собой backend-сервис для загрузки и управления дронами и маршрутами
Технологии: Node.js + Express.js + MongoDB
Версия: 1.0.0
Порт: 3000

## АРХИТЕКТУРА И СТРУКТУРА

### Основные компоненты:
- Express.js сервер с модульной архитектурой
- MongoDB для хранения данных
- JWT аутентификация с ролевой моделью
- Minio для хранения файлов
- Prometheus метрики для мониторинга
- Docker контейнеризация

### Структура проекта:
```
src/
├── app.js           - Основная конфигурация Express приложения
├── server.js        - Точка входа сервера
├── config/          - Конфигурационные файлы
├── controllers/     - Контроллеры для обработки HTTP запросов
├── middleware/      - Промежуточное ПО
├── models/          - Mongoose модели данных
├── routes/          - Определение маршрутов API
├── services/        - Бизнес-логика и внешние сервисы
├── utils/           - Утилиты и вспомогательные функции
└── validations/     - Схемы валидации входящих данных
```

## РЕАЛИЗОВАННЫЕ ФИЧИ

### 1. СИСТЕМА АУТЕНТИФИКАЦИИ И АВТОРИЗАЦИИ
- JWT токены для аутентификации
- Ролевая модель доступа (admin, operator, viewer)
- Регистрация пользователей (/api/auth/register)
- Вход в систему (/api/auth/login)
- Получение профиля пользователя (/api/auth/profile)
- Middleware для проверки токенов и ролей

### 2. УПРАВЛЕНИЕ ДРОНАМИ
Эндпоинты для дронов (/api/drones):
- GET /api/drones - получение списка всех дронов
- POST /api/drones - создание нового дрона (только admin)
- GET /api/drones/:id - получение дрона по ID
- PUT /api/drones/:id - обновление дрона (только admin)
- DELETE /api/drones/:id - удаление дрона (только admin)
- POST /api/drones/:id/status - обновление статуса дрона
- GET /api/drones/:id/telemetry - получение телеметрии дрона

### 3. УПРАВЛЕНИЕ МАРШРУТАМИ
Эндпоинты для маршрутов (/api/routes):
- GET /api/routes - получение всех маршрутов
- POST /api/routes - создание нового маршрута
- GET /api/routes/:id - получение маршрута по ID
- PUT /api/routes/:id - обновление маршрута
- DELETE /api/routes/:id - удаление маршрута
- POST /api/routes/:id/assign/:droneId - назначение дрона на маршрут
- POST /api/routes/:id/execute - выполнение маршрута

### 4. ХРАНЕНИЕ ФАЙЛОВ
- Интеграция с MinIO для хранения файлов
- Поддержка загрузки и получения файлов
- Методы: uploadFile, downloadFile, deleteFile, listFiles

## МОДЕЛИ ДАННЫХ

### User (Пользователь):
- username: уникальное имя пользователя
- email: электронная почта
- password: хешированный пароль
- role: роль (admin/operator/viewer)
- createdAt/updatedAt: временные метки

### Drone (Дрон):
- name: название дрона
- model: модель дрона
- serialNumber: серийный номер
- status: статус (active/inactive/maintenance/offline)
- batteryLevel: уровень заряда батареи
- location: текущие координаты (latitude, longitude, altitude)
- lastSeen: время последней активности
- firmware: версия прошивки
- capabilities: возможности дрона

### Route (Маршрут):
- name: название маршрута
- description: описание
- waypoints: массив точек маршрута с координатами
- status: статус (planned/active/completed/cancelled)
- assignedDrone: назначенный дрон
- estimatedDuration: ожидаемая продолжительность
- createdBy: создатель маршрута

## MIDDLEWARE И СЕРВИСЫ

### Middleware:

- metrics.js - сбор метрик Prometheus
- validation.js - валидация входящих данных
- autoWrapRoutes.js - автоматическая обертка маршрутов

### Сервисы:
- minio.service.js - работа с файловым хранилищем MinIO
- scv.service.js - дополнительные сервисы

## ВАЛИДАЦИЯ ДАННЫХ

### Drone Validation:
- Проверка обязательных полей (name, model, serialNumber)
- Валидация статуса дрона
- Проверка координат и уровня батареи

### Route Validation:
- Валидация waypoints (координаты, высота)
- Проверка статуса маршрута
- Валидация временных параметров

## ПОДДЕРЖИВАЕМЫЕ WORKFLOW

### 1. Управление пользователями:
- Регистрация → Вход → Получение профиля
- Ролевое разграничение доступа к функциям

### 2. Управление дронами:
- Создание дрона → Настройка → Мониторинг статуса
- Обновление телеметрии → Отслеживание местоположения

### 3. Планирование миссий:
- Создание маршрута → Назначение дрона → Выполнение
- Мониторинг выполнения → Получение результатов

### 4. Файловый документооборот:
- Загрузка файлов → Хранение в MinIO → Скачивание
